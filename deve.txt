# Icon Assets Guide

This extension requires icon assets in multiple sizes for different use cases.

## Required Icons

Create the following icon files in the `assets/icons/` directory:

### Icon Sizes

- **icon16.png** - 16x16px - Toolbar icon (small)
- **icon32.png** - 32x32px - Windows taskbar
- **icon48.png** - 48x48px - Extension management page
- **icon128.png** - 128x128px - Chrome Web Store, installation

## Design Guidelines

### Style
- **Modern and Clean** - Follow current design trends
- **Recognizable** - Should be instantly recognizable as Instagram-related
- **Gradient** - Use the purple gradient (#667eea to #764ba2)
- **Download Icon** - Incorporate a download arrow or symbol

### Recommended Design

Main icon should feature:
1. Instagram camera outline or stylized "IG" letters
2. Download arrow pointing down
3. Purple gradient background (#667eea → #764ba2)
4. Rounded corners with 20% border radius

### Color Palette

Primary Gradient:

Start: #667eea (Purple Blue)

End: #764ba2 (Deep Purple)

Accent Colors:

White: #ffffff (for icons/text)

Shadow: rgba(0, 0, 0, 0.1)

## Creating Icons

### Option 1: Using Figma (Recommended)

1. Create a new Figma file
2. Create 128x128px frame
3. Design your icon:
Background: Rectangle with gradient (#667eea → #764ba2)

Corner radius: 26px (20%)

Add download arrow icon (white)

Add Instagram camera outline (white, subtle)

text
4. Export as PNG at 1x, 2x scales
5. Resize to required dimensions:
- 128x128px (original)
- 48x48px (scale down)
- 32x32px (scale down)
- 16x16px (scale down)

### Option 2: Using Adobe Illustrator

1. Create 128x128px artboard
2. Draw icon with vector shapes
3. Apply gradient fill
4. Export for screens at required sizes

### Option 3: Using Online Tools

**Recommended Tools:**
- [Figma](https://figma.com) - Free, web-based
- [Canva](https://canva.com) - Easy templates
- [Photopea](https://photopea.com) - Free Photoshop alternative

**Icon Generators:**
- [RealFaviconGenerator](https://realfavicongenerator.net/)
- [Favicon.io](https://favicon.io/)

## SVG Source (Optional)

Create a master SVG icon for easy scaling:

### icon.svg

```svg
<svg width="128" height="128" viewBox="0 0 128 128" fill="none" xmlns="http://www.w3.org/2000/svg">
<defs>
 <linearGradient id="gradient" x1="0%" y1="0%" x2="100%" y2="100%">
   <stop offset="0%" style="stop-color:#667eea;stop-opacity:1" />
   <stop offset="100%" style="stop-color:#764ba2;stop-opacity:1" />
 </linearGradient>
</defs>

<!-- Background -->
<rect width="128" height="128" rx="26" fill="url(#gradient)"/>

<!-- Download Arrow -->
<path d="M64 32 L64 72 M64 72 L48 56 M64 72 L80 56" 
     stroke="white" 
     stroke-width="6" 
     stroke-linecap="round" 
     stroke-linejoin="round"/>

<!-- Base Line -->
<path d="M40 88 L88 88" 
     stroke="white" 
     stroke-width="6" 
     stroke-linecap="round"/>

<!-- Instagram Camera (subtle, optional) -->
<circle cx="64" cy="52" r="12" 
       stroke="white" 
       stroke-width="2" 
       fill="none" 
       opacity="0.3"/>
</svg>

Validation
After creating icons, validate them:

Size Check: Ensure exact pixel dimensions

Format Check: Must be PNG with transparency

Quality Check: No pixelation or artifacts

Visibility Check: Test on both light and dark backgrounds

## File Purposes

### Root Files

| File | Purpose |
|------|---------|
| `manifest.json` | Extension configuration and permissions |
| `package.json` | NPM dependencies and build scripts |
| `webpack.config.js` | Build system configuration |
| `.babelrc` | JavaScript transpilation settings |
| `.gitignore` | Files to exclude from version control |

### Background (`src/background/`)

Service worker that runs in the background, handling:
- Session management
- Download coordination
- Network monitoring
- Message routing

### Content (`src/content/`)

Scripts injected into Instagram pages:
- Profile scanning
- UI injection
- Credential extraction
- User interaction handling

### Core (`src/core/`)

Shared core functionality:
- Logging system
- Storage abstraction
- Error handling
- Media URL extraction

### UI (`src/ui/`)

All user interface pages and components:
- **Popup**: Quick access toolbar popup
- **Preview**: Media selection interface
- **Onboarding**: First-time user setup
- **Options**: Full settings page
- **Components**: Reusable UI elements

### Styles (`src/styles/`)

Global styling system:
- CSS variables and design tokens
- Theme management (light/dark)
- Animation utilities
- Responsive utilities

### Utils (`src/utils/`)

Helper functions and utilities used across the codebase

Code Organization Principles
1. Separation of Concerns
Background services separate from content scripts

UI components separate from business logic

Core modules reusable across contexts

2. Single Responsibility
Each file has one clear purpose

Classes and functions do one thing well

Easy to test and maintain

3. Dependency Injection
Managers receive dependencies

Easy to mock for testing

Loose coupling

4. Event-Driven Architecture
Message passing for cross-context communication

Event listeners for user interactions

Observer pattern for state changes
